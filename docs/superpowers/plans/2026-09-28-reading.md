# Reading Experience Implementation Plan

**Goal:** Notes read in the chosen "C · Crisp" style. Long notes get ↑Top/‹Prev/Next› section jumping (buttons plus Alt+↓/↑) and Ctrl+F find-in-note. Touchpad pinch-to-zoom works smoothly.

**Architecture:** Everything is frontend-only inside the note editor (`PageEditor.tsx`).
- Section detection is one pure function over BlockNote blocks (`lib/note-sections.ts`), unit-tested.
- Scrolling and navigation live in `lib/section-nav.ts`, shared by the floating buttons and the keyboard shortcut.
- Find uses the CSS Custom Highlight API, so the note's DOM and content are never modified.

**Tech Stack:** React 19, BlockNote 0.47.3, TypeScript, CSS custom properties (OKLCH tokens), vitest (run from `packages/core`).

**Spec:** `docs/superpowers/specs/2026-09-28-reading-design.md` — read it first.

- **Never write to the local SQLite file directly.** Read it only through the app's IPC (`plugin:sql|select`).
- **No full-desktop screenshots.** Verify through CDP, then ask the user to look.
- **Style C values (exact):**
  - body 17px × `--reading-scale`, line-height 1.55, column 72ch;
  - light: body ink `oklch(0.15 0 0)` on `oklch(1 0 0)`;
  - dark: body ink `oklch(0.96 0.003 30)` on the existing surface;
  - headings weight 700, H1/H2 with a 1px bottom rule.
- **Section rule (exact):**
  - If the note has any heading block, only headings are sections.
  - Otherwise a top-level paragraph is a section start if it's **fully bold**, or if its trimmed text is 1–60 characters, doesn't end in `.` `,` `;` `:`, **and** a non-empty block follows it.
- **Keys:** Alt+↓ is next section and Alt+↑ is previous. They must `preventDefault()` + `stopPropagation()` in the **capture** phase, so ProseMirror never acts on them. No single-letter shortcuts, because the note is always editable.
- **Find must never modify the note:** no `<mark>` insertion and no editor transactions. `page_bodies.updated_at` must be unchanged after searching.
- **The user is a non-developer.** Keep updates short and plain.

```ts
// Where a "section" starts in a note, for the ↑Top/‹Prev/Next› jumper and
// Alt+↓/↑. Most of the user's notes have no headings, so when a note has
// none, bold-only lines and short title-like lines ("FROM", "WHERE",
// "Market entry") count instead. Pure and dependency-free so it's
// unit-testable (see note-sections.test.ts).

export interface SectionBlock {
  id: string;
  type: string;
  content?: unknown;
}

interface TextRun {
  type?: string;
  text?: string;
  styles?: { bold?: boolean };
}

const MAX_TITLE_CHARS = 60;
const TRAILING_PUNCTUATION = /[.,;:]$/;

function runs(block: SectionBlock): TextRun[] {
  return Array.isArray(block.content) ? (block.content as TextRun[]) : [];
}

function plainText(block: SectionBlock): string {
  return runs(block)
    .map((r) => (typeof r.text === "string" ? r.text : ""))
    .join("")
    .trim();
}

/** Anything other than an empty paragraph counts as content. */
function hasContent(block: SectionBlock): boolean {
  if (block.type !== "paragraph") return true;
  return plainText(block).length > 0;
}

function isFullyBold(block: SectionBlock): boolean {
  const visible = runs(block).filter((r) => typeof r.text === "string" && r.text.trim().length > 0);
  return visible.length > 0 && visible.every((r) => r.styles?.bold === true);
}

function isTitleLike(block: SectionBlock): boolean {
  const t = plainText(block);
  return t.length > 0 && t.length <= MAX_TITLE_CHARS && !TRAILING_PUNCTUATION.test(t);
}

export function findSectionStarts(blocks: readonly SectionBlock[]): string[] {
  const headings = blocks.filter((b) => b.type === "heading").map((b) => b.id);
  if (headings.length > 0) return headings;

  const out: string[] = [];
  blocks.forEach((block, i) => {
    if (block.type !== "paragraph") return;
    if (isFullyBold(block)) {
      out.push(block.id);
      return;
    }
    if (!isTitleLike(block)) return;
    // A title only counts if some content follows it.
    if (blocks.slice(i + 1).some(hasContent)) out.push(block.id);
  });
  return out;
}
```

```ts
// DOM side of section jumping. BlockNote renders every block as
// `.bn-block-outer[data-id="<blockId>"]`, and the note scrolls inside the
// nearest `.app-pane` (overflow-y: auto). Jumping only scrolls — it never
// moves the text cursor, so reading can't turn into an accidental edit.

const EDGE_PX = 8;

export function scrollParentOf(el: HTMLElement): HTMLElement {
  return (el.closest(".app-pane") as HTMLElement | null) ?? document.scrollingElement as HTMLElement ?? el;
}

function blockEl(container: HTMLElement, id: string): HTMLElement | null {
  return container.querySelector(`.bn-block-outer[data-id="${CSS.escape(id)}"]`);
}

export function jumpToSection(container: HTMLElement, ids: string[], dir: 1 | -1): void {
  const parent = scrollParentOf(container);
  const top = parent.getBoundingClientRect().top;
  const positions = ids
    .map((id) => ({ id, el: blockEl(container, id) }))
    .filter((x): x is { id: string; el: HTMLElement } => x.el !== null)
    .map((x) => ({ ...x, y: x.el.getBoundingClientRect().top - top }));
  const target =
    dir === 1
      ? positions.find((p) => p.y > EDGE_PX)
      : [...positions].reverse().find((p) => p.y < -EDGE_PX);
  target?.el.scrollIntoView({ block: "start", behavior: "smooth" });
}

export function jumpToTop(container: HTMLElement): void {
  scrollParentOf(container).scrollTo({ top: 0, behavior: "smooth" });
}

/** True when the note is long enough that jumping helps (> 1.5 screens). */
export function isLongNote(container: HTMLElement): boolean {
  const parent = scrollParentOf(container);
  return parent.scrollHeight > parent.clientHeight * 1.5;
}
```

```tsx
import { useEffect, useState } from "react";
import { ArrowUp, ChevronLeft, ChevronRight } from "lucide-react";
import { isLongNote, jumpToSection, jumpToTop, scrollParentOf } from "../lib/section-nav";

interface SectionJumperProps {
  container: HTMLElement | null;
  sectionIds: string[];
}

/** Floating ↑ Top · ‹ Prev · Next › for long notes (reading spec §2). */
export function SectionJumper({ container, sectionIds }: SectionJumperProps) {
  const [visible, setVisible] = useState(false);

  useEffect(() => {
    if (!container) return;
    const parent = scrollParentOf(container);
    const update = () => setVisible(isLongNote(container));
    update();
    const ro = new ResizeObserver(update);
    ro.observe(container);
    parent.addEventListener("scroll", update, { passive: true });
    return () => {
      ro.disconnect();
      parent.removeEventListener("scroll", update);
    };
  }, [container, sectionIds]);

  if (!container || !visible) return null;
  const hasSections = sectionIds.length > 0;

  return (
    <div className="section-jumper" data-section-count={sectionIds.length}>
      <button className="section-jumper__btn" title="Back to top (Ctrl+Home)" onClick={() => jumpToTop(container)}>
        <ArrowUp size={13} strokeWidth={2} /> Top
      </button>
      <button
        className="section-jumper__btn"
        title="Previous section (Alt+↑)"
        disabled={!hasSections}
        onClick={() => jumpToSection(container, sectionIds, -1)}
      >
        <ChevronLeft size={13} strokeWidth={2} /> Prev
      </button>
      <button
        className="section-jumper__btn"
        title="Next section (Alt+↓)"
        disabled={!hasSections}
        onClick={() => jumpToSection(container, sectionIds, 1)}
      >
        Next <ChevronRight size={13} strokeWidth={2} />
      </button>
    </div>
  );
}
```

```tsx
import { useEffect, useMemo, useRef, useState } from "react";
import { ChevronDown, ChevronUp, X } from "lucide-react";

// Find-in-note using the CSS Custom Highlight API: we build Range objects
// over the editor's text nodes and register them as named highlights,
// styled in App.css via ::highlight(). Nothing is inserted into the DOM and
// no editor transaction happens, so searching can never modify the note or
// trigger a save. Known limit: a match split across two differently
// formatted runs (e.g. half bold) isn't found.

interface HighlightLike {
  new (...ranges: Range[]): unknown;
}
interface HighlightRegistryLike {
  set(name: string, value: unknown): void;
  delete(name: string): void;
}

const registry = (): HighlightRegistryLike | undefined =>
  (CSS as unknown as { highlights?: HighlightRegistryLike }).highlights;
const HighlightCtor = (): HighlightLike | undefined =>
  (window as unknown as { Highlight?: HighlightLike }).Highlight;

function findRanges(root: HTMLElement, query: string): Range[] {
  const q = query.toLowerCase();
  if (!q) return [];
  const out: Range[] = [];
  const walker = document.createTreeWalker(root, NodeFilter.SHOW_TEXT);
  for (let node = walker.nextNode(); node; node = walker.nextNode()) {
    const text = (node.nodeValue ?? "").toLowerCase();
    let from = 0;
    for (let at = text.indexOf(q, from); at !== -1; at = text.indexOf(q, from)) {
      const range = document.createRange();
      range.setStart(node, at);
      range.setEnd(node, at + q.length);
      out.push(range);
      from = at + q.length;
    }
  }
  return out;
}

interface NoteFindBarProps {
  container: HTMLElement;
  docVersion: number;
  onClose: () => void;
}

  const ranges = useMemo(() => {
    const root = container.querySelector(".bn-editor") as HTMLElement | null;
    return root ? findRanges(root, query) : [];
    // docVersion: recompute when the note text changes

    },

  );

    if (ranges.length === 0) return;

  };

  return (

      <input
        ref={inputRef}
        className="note-find__input"
        placeholder="Find in note"
        value={query}
        onChange={(e) => setQuery(e.target.value)}
        onKeyDown={(e) => {
          if (e.key === "Enter") {
            e.preventDefault();
            step(e.shiftKey ? -1 : 1);
          } else if (e.key === "Escape") {
            e.preventDefault();
            onClose();
          }
        }}
      />
      <span className="note-find__count">{query ? (ranges.length ? `${index + 1} of ${ranges.length}` : "No matches") : ""}</span>
      <button className="icon-btn" title="Previous (Shift+Enter)" onClick={() => step(-1)} disabled={ranges.length === 0}>
        <ChevronUp size={14} strokeWidth={2} />
      </button>
      <button className="icon-btn" title="Next (Enter)" onClick={() => step(1)} disabled={ranges.length === 0}>
        <ChevronDown size={14} strokeWidth={2} />
      </button>
      <button className="icon-btn" title="Close (Esc)" onClick={onClose}>
        <X size={14} strokeWidth={2} />
      </button>
    </div>
  );
}
```

### Task 5: Touchpad pinch-to-zoom — diagnose, then fix

**Files:**
- Modify: `apps/desktop/src/components/PageEditor.tsx`. The existing effect is under the comment `// Ctrl+scroll / pinch zoom on the reading area`.

The current handler steps ±0.1 per wheel event and listens only on `.page-editor`. Two likely failure modes:
1. A touchpad pinch fires dozens of tiny Ctrl+wheel events per gesture, so it slams to 80%/200% instantly and feels broken.
2. Pinching over the pane's margins or the outline rail is outside `.page-editor`, so nothing happens.

Fix both here. Then diagnose with the user in Task 6 to confirm there's no third cause.

- [x] **Step 1: Replace the whole wheel-zoom `useEffect`** (from the `// Ctrl+scroll / pinch zoom` comment through its closing `}, []);`) with:

```ts
  // Ctrl+scroll / touchpad pinch zoom on the reading area. Windows delivers
  // a touchpad pinch as a burst of Ctrl+wheel events with small deltaY, and
  // a mouse notch as one event with |deltaY|≈100 — so scale proportionally
  // (exp) instead of a fixed ±0.1 per event, which made a pinch jump
  // straight to 80%/200%. Listens on the whole scrolling pane (not just the
  // editor column) so pinching over the margins or outline rail works too.
  // passive:false is mandatory to be allowed to preventDefault.
  useEffect(() => {
    const el = containerRef.current;
    if (!el) return;
    const target = (el.closest(".app-pane") as HTMLElement | null) ?? el;
    const onWheel = (e: WheelEvent) => {
      if (!e.ctrlKey) return;
      e.preventDefault();
      const factor = Math.exp(-e.deltaY * 0.001);
      setReadingScale((s) => {
        const next = Math.min(2, Math.max(0.8, Math.round(s * factor * 1000) / 1000));
        writePref("scale", String(next));
        return next;
      });
    };
    target.addEventListener("wheel", onWheel, { passive: false });
    return () => target.removeEventListener("wheel", onWheel);
  }, []);
```
